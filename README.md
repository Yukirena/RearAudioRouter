RearAudioRouter

- 2채널 장치의 입력을 멀티채널 출력장치의 후면 스피커로 출력
- WASAPI Shared 모드 사용
- 후면 스피커가 포함된 4채널 이상의 출력장치 필요
- Windows Audio Engine을 통하여 입출력 장치간 서로 다른 샘플링 레이트 사용 가능
- 최소화시 시스템 트레이로 숨김
- 윈도우 시작시 자동실행

- Routes a stereo input device to the Rear L/R channels
  of a multichannel Windows audio device.
- Uses WASAPI Shared Mode.
- Requires a 4-channel or greater output configuration
  with Rear L/R channels.
- Supports different input/output sample rates via
  Windows Audio Engine conversion.
- Can run in the system tray.
- Can start automatically with Windows.
